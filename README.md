# Crop Health Detection

About the Project:
This project uses Deep Learning to identify crop diseases from leaf images. It compares CNN, VGG16, and ResNet50 models to predict crop diseases and help farmers understand potential crop health issues.

Features: 
1. Upload a crop leaf image for disease prediction.
2. Predict the crop disease using a trained Deep Learning model.
3. Compare CNN, VGG16, and ResNet50 performance.
4. Display prediction confidence.
5. Provide basic crop health advisory information.

Technologies Used:
1. Python
2. TensorFlow and Keras
3. Convolutional Neural Networks (CNN)
4. VGG16 and ResNet50
5. NumPy, Matplotlib and Scikit-learn
6. Google Colab

Dataset:
The project uses the PlantVillage dataset for crop disease classification.

How to Run:
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Train and evaluate the models.
4. Upload a crop leaf image in the prediction section.
5. View the predicted disease and confidence score.
Project Objective

To explore how Deep Learning can support early crop disease detection and provide useful information for farmers.
